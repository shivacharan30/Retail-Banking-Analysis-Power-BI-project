# Retail Banking Analysis using Power BI

## Project Overview

This project focuses on analyzing retail banking data using Microsoft Power BI.

The main objective is to understand customer activity, account performance, transaction success, loan repayment performance, and product engagement through interactive dashboards and Key Performance Indicators (KPIs).

## Project Objectives

- Analyze customer and account growth.
- Monitor total account balances.
- Evaluate transaction success rates.
- Identify loan delinquency and late payments.
- Analyze outstanding loan balances.
- Understand customer product engagement.
- Support better business decision-making.

## Tools & Technologies

- Microsoft Power BI
- Power Query (if used in the final report)
- DAX (Data Analysis Expressions)
- Data Visualization

## Key Performance Indicators (KPIs)

### 1. Customer & Account Growth
- Active Customer Rate
- Active Account Rate

### 2. Value & Revenue
- Total Account Balance
- Transaction Success Rate

### 3. Loan Performance
- Loan Delinquency Rate
- Late Payment Rate
- Total Outstanding Loan Balance

### 4. Product Engagement
- Multi-Product Customer Rate

## Key Findings

Based on the documented baseline analysis:

- Loan Delinquency Rate: 56.3%
- Late Payment Rate: Approximately 25%
- Transaction Success Rate: Approximately 33.8%
- Outstanding Loan Balance: Approximately 53.4 million

These findings highlight areas requiring management attention, especially loan repayment performance and transaction processing.
